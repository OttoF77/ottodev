Sysotto Multi-Tenant Core & Security Engine

Shared infrastructure spine, identity federation, and distributed microservices orchestration.

Business Problem: Risk of cross-tenant data leakage in shared database architectures and authentication bottlenecks across microservices.
Architecture & Implementation (Otto Freitag): Fail-closed tenant resolution middleware, database migration runner with concurrent advisory locks, and OpenIddict / JWT authorization pipeline.
Implemented architectural scope: Dynamic tenant resolution via middleware (MonolithTenantProvider) preventing tenant injection, PostgreSQL Row Level Security (RLS) data isolation, OAuth2 / OIDC authorization with OpenIddict, and Redis distributed caching.
Planned technical evolution: Unified SSO identity portal with centralized tenant telemetry and billing usage dashboards.
Stack: C# .NET 10, OpenIddict, PostgreSQL 17, Redis, Docker Compose, Linux.
